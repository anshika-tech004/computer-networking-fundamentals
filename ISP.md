## Internet Service Provider
- It is a company or organization that provides individuals and businesses with access to the Internet.
- Example- Jio, airtel, idea, BSNL (companies)

## Role of ISP
- Internet connectivity
- IP addressing
- Provides different connection speeds and manages network capacity.
- Security services (traffic filtering, DDoS protection, or abuse monitoring.)
- Additional services (email, web hosting, VPNs, or cloud connectivity.) 

> (my understanding)
    I think it connects customers to the Internet through technologies such as fiber, DSL, cable, mobile networks, or satellite.

## How IP Addressing and DNS Enable Internet Connectivity
1. IP Addressing

An IP address identifies a device or network interface so that data can be delivered to the correct destination.

For example:

   My Device
IP: 192.168.1.10
        ↓
     Router
        ↓
      ISP
        ↓
     Internet

2. DNS (Domain Name System)
   - We  prefer names such as: google.com
   - Computers communicate using IP addresses.
   - DNS translates a domain name into an IP address.
   - ex:
   google.com
      ↓
     DNS
     ↓
   IP Address
      ↓
  Web Server

- How They Work Together
  
User enters a domain name
          ↓
        DNS
          ↓
Finds the destination IP address
          ↓
Router forwards packets
          ↓
ISP routes traffic
          ↓
Internet
          ↓
Destination Server
